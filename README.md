# anna-meyuhas.com

אתר אנה מיוחס — פסיכותרפיה גופנית־נפשית נשית.

## מבנה

- `index.html` — דף הבית (רכיב x-dc יחיד, לוגיקה בתחתית הקובץ)
- `support.js` — ספריית הרנדור של הרכיב
- `articles/` — חמישה מאמרים כעמודים עצמאיים
- `illustrations/` — איורי אקוורל (WebP)
- `og-image.jpg` — תמונת שיתוף לרשתות
- `sitemap.xml`, `robots.txt` — SEO

## שירותים מחוברים

- **אחסון:** Netlify (פרויקט anna-meyuhas)
- **טפסים:** Netlify Forms — הטופס `contact`, התראות למייל
- **יומן:** Calendly — https://calendly.com/meyuhastv/30min
- **דומיין:** Porkbun → ALIAS ל-apex-loadbalancer.netlify.com

## עריכה

כל שינוי נעשה ישירות בקבצים. לתצוגה מקדימה — לפתוח את `index.html` בדפדפן
(שליחת טופס לא תעבוד מקומית, זה תקין).

push ל-main מפרסם אוטומטית.
